## 样本身份

|---|---:|---|

| `19si.exe` | 1,199,616 | `5afbebb7ed01515ed80ca9c9e7e4c7b01c7652e220b2c2a19452356688e79244` |

两个原EXE位于 `samples/17si-19si.samples.zip`，ZIP密码为 **`infected`**，采用ZIP AES256。请使用支持该格式的7-Zip等工具。这个公开密码用于避免无意解压和误操作，不是保密措施。

`recovered/reconstructed-payloads.zip` 使用同一密码。它包含分析工程使用的内层PE映像，PE头和分析基址已有重建/规范化；具体输入hash、基址和调整记录见 `evidence/analysis-inputs.json`。**这些内层映像同样不能在宿主机加载或运行。**

样本hash以ZIP内成员的原始字节为准。ZIP自身的hash另列于 `SHA256SUMS`。

## 已确认的行为

- 扩展从软件选择接口取得ZIP信息、hash和入口，校验ZIP后解压并后台启动EXE。
- 外层EXE恢复内嵌DLL并手工映射到Explorer；样本包含环境检测和沙箱提示窗口。
- 内层首次POST发送主机信息，接收这一轮配置；采集文件、注册表值、浏览器与扩展存储，以及指定应用令牌。
- 浏览器路径包含进程内存读取、线程上下文操作和同进程解保护调用准备。
- 结果经过序列化、压缩及应用层包装，进入发往 `hebaoshi[.]co:443` 的HTTPS POST。
- 可按配置截图、替换剪贴板中的指定格式地址，并下载启动新程序。

保存的一份真实配置快照含325个文件任务、390组根路径、787条匹配规则及3个注册表任务。配置可以变化；其他设备上的样本版本也可能不同。

## 恢复代码与当前边界

`assembly.asm` 是对应分析输入的完整可执行节线性反汇编；`decompiled.c` 按RVA汇集当前选中的C表示。分析者分配的名称和类型、编译器优化以及未恢复分支均会影响C的可读性。它不是作者原始工程，也不是可直接重新编译的木马项目。

`verified/` 单独保存已完成正常上下文控制流及来源复核的网络、文件和浏览器核心。其余函数的状态请看相邻 `functions.csv`，不要用“C文件存在”判断行为已穷尽。

Chrome156已核对源码、安装代码和历史只读现场：发现v10/v20受保护键对象，完整访问句柄实际成功。目标线程执行及数据库记录认证尚未实际核验；详细状态见报告。

公开材料不包含真实密码、token或私钥原值，也不包含本机认证数据库或浏览器数据库。报告保留事件核验的数量与类型。文本中的分析工作区和用户目录已作路径脱敏，原始文本hash与公开文本hash的对应见 `evidence/provenance.json`。

## 校验

在仓库根目录执行 `python tools/verify_integrity.py`，核对 `SHA256SUMS`。该工具只读取文件并计算hash，不解压或执行样本。`.gitattributes` 禁止自动换行转换，以保持发布文件的字节校验值。
